## 3. Root causes retenues (opposables)

### RC1 — Hoist two-pass / regType (F-hoist-regtype)
- pass1 appelle `writeAssign` en mode collect **avant** que certains `regType[dst]` soient finalisés (ex. ordre OpCall : writeAssign puis `regType=dom`).
- Declaration `var v T` utilise un type unique ; assign ultérieur d’un type plus étroit (byte) ou plus large (call uint32→slot uint64) casse.
- Mitigation partielle dans tree : hoistTypes + regType après pass1 ; Load cast vers targetT ; **pas suffisant** pour field stores.

### RC2 — OpField / OpStore elem default uint8
- `OpField` sans Elem → `regType = TypUint8`.
- `OpStore` lit `ins.Elem` / `regType[base]` ; si base est expression `ctx.H` mal typée → cast `uint8(val)` dans `arg()`.
- Array fields `h[5]` doivent porter **Elem=uint32** + ArrayLen dès le front.

### RC3 — ptrMeta / regs locaux dans pe() (critique fin session)
- Param `ctx *T` a ptrMeta sur le registre param.
- Expression parsing crée un scratch ; lookup struct name / field type se fait sur le **mauvais** registre → sname vide → fallback uint8.
- **Action :** ptrMeta et struct binding doivent suivre les alias de registres (union-find / copy meta on move), ou pe ne doit pas rebind le nom `ctx`.

### RC4 — harvestStructs regex fragile
- `typedef struct {([^}]*)} Name` : OK monoline body segments ; multi-line body ok via `[^}]*` (dotall non requis car `[^}]` mange newlines).
- `reF` exige type+name exact ; espaces / macros / `const` peuvent dropper des champs.
- Test ajouté : `TestHarvestStructsMono` (PASS en session).

### RC5 — Array field → slice call arg
- `Load32_le_buf(ctx.R, …)` doit émettre `ctx.R[:]` (array→slice).
- Fix arg() : si Imm/ArrayLen ou elemIdx sur field, suffixe `[:]`.
- Partiellement appliqué ; régressions observées quand field type perdu.

### RC6 — pad[i] / indexation champ array
- Émis : `v + ctx.Pad[:]` au lieu de `ctx.Pad[i]` ou load elem.
- Front doit produire OpLoad(base=field, idx) pas OpAdd(scalar, slice).

### RC7 — writeAssign sur non-lvalue
- `ctx.R[:] := x` : `declared[dst]` false pour dst qui n’est pas un temp simple.
- Ne jamais `:=` si `regName[dst]` contient `.` ou `[`.

### RC8 — FillStubs / symboles synthétiques
- `__cmp___` redeclared sur amalg complet non filtré.
- Filtrer emit aux symboles AEAD **ou** dédup stubs par nom canonique.

### RC9 — Hoist dead temps
- `declared and not used: v87` : hoist déclare tous les dst du pass1 y compris dead / branch-only sans prune.

### RC10 — Curseur cipher_text += (sémantique, hors build)
- Observé sur mono_aead.go antérieur : reset d’offSlot dans boucle (F-go-block-scope / cursor).
- Non clôturé KAT dans cette session.

### RC11 — blake2b 2D (dogfood j)
- `blake2b_sigma[r][2*0]` harvest_fail — index 2D hors subset.
- Distinct monocypher mais même backlog front arrays.
